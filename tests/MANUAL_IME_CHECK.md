# 한글 IME 수동 확인 (WebView2)

자동 테스트(`npm test`)는 합성 `compositionstart`/`compositionend` 이벤트로 저장 보류 로직만 검증합니다.
실제 Windows IME 입력은 아래 절차로 사람이 확인합니다.

1. `npm run tauri dev`로 앱을 실행하고 새 메모를 엽니다.
2. 한글 IME로 `강남역 앞에서 만났다`를 빠르게 입력합니다.
   - 입력 중 상태 배지가 **한글 조합 중 (저장 보류)** 로 바뀌는지 확인
   - 받침 쪼개짐(`가ㅇ`), 글자 유실, 커서 튐이 없는지 확인
3. 입력을 멈추고 약 0.5초 뒤 배지가 **저장됨** 으로 바뀌는지 확인합니다.
4. 앱을 종료했다가 다시 열어 같은 문장이 그대로 남아 있는지 확인합니다.
5. 조합 중(마지막 글자 밑줄 상태)에 다른 문서를 클릭하고, 돌아왔을 때 내용이 남아 있는지 확인합니다.
